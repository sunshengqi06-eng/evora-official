## EVORA 是什么

EVORA 提供 OpenAI 兼容接口，帮助用户通过统一的 API Key 接入 AI 模型，并可在 Codex、CC Switch 及其他兼容 OpenAI 接口的应用中使用。

## 主要能力

- **统一接口**：通过 OpenAI 兼容协议接入，减少重复配置。
- **灵活选模**：创建密钥时可选择指定模型或不限制模型。
- **能量计费**：账户统一显示能量余额，用量与扣费记录可查询。
- **工具接入**：提供 Codex、CC Switch 等工具的配置说明。
- **模型广场**：集中查看当前展示的模型与计费信息。
- **人工客服**：官网提供在线客服入口，方便处理接入与账户问题。

## 快速开始

1. 进入 [EVORA 官网](https://evora-token-reseller.vercel.app/) 注册并登录。
2. 在控制台创建 API Key，并确认需要使用的模型。
3. 打开 [接入文档](https://evora-token-reseller.vercel.app/docs)，按照对应工具完成配置。
4. 在控制台查看能量余额、调用次数、用量及扣费记录。

## 使用提示

- 请妥善保管 API Key，不要公开提交到 GitHub 或发送给无关人员。
